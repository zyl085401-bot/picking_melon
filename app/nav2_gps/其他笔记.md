# 常用指令

### ROS2
- 创建工作空间：```mkdir -p <name>/src```
- 创建功能包：```ros2 pkg create <name> --build-type ament_cmake --dependencies rclcpp```
  - --build-type 用来指定该包的编译类型，一共有三个可选项ament_python、ament_cmake、cmake
  - --dependencies 指的是这个功能包的依赖，rclcpp是ros2的C++客户端接口
- 使用colcon编译：```colcon build```
- 添加可执行权限：```chmod +x <name>```

### SLAM
- 保存地图：```ros2 run nav2_map_server map_saver_cli -f ~/<name>```

### USB相机标定
标定板生成： [calab.io](https://calib.io/pages/camera-calibration-pattern-generator)
- 找到棋盘格标定板，棋盘格内角点数量记为7x10，单格边长为0.015 （单位：m）
- 启动相机：``` ros2 run usb_cam usb_cam_node_exe```
- 启动标定程序：```ros2 run camera_calibration cameracalibrator --size 7x10 --square 0.015 image:=/image_raw --no-service-check```
- 标定完成后SAVE，COMMIT，文件位于```/tmp/calibrationdata.tar.gz```
